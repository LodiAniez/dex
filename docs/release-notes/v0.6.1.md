# Dex 0.6.1

A fix for switching running panes between PowerShell and WSL, a settings gear, and a **+** on every pane.

**Download:**
- **Windows:** `Dex_0.6.1_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet, so SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it, and your workspaces, hooks and settings are kept.
- **macOS:** `Dex_0.6.1_macos_apple-silicon.dmg` for an M-series Mac, `Dex_0.6.1_macos_intel.dmg` for an Intel one. macOS 11 or later. The first launch needs **Open Anyway**, as before.

All three appear a few minutes after the release, once GitHub has built them.

## Fixed

- **Restarting a pane in another terminal.** In 0.6.0, choosing Ubuntu and restarting a running PowerShell pane could leave it showing `[process exited with code 1]` instead of moving it. The library Dex uses to end a shell reports a successful kill as a failure on Windows, and 0.6.0 only caught the common case of that. Now the restart works both ways, from PowerShell to WSL and back.
- **The Restart button right after choosing a terminal.** It stayed disabled for a second or two while Dex re-ran its checks, so a quick click did nothing. It now works as soon as the question appears.
- **Splitting a markdown pane** (with `Ctrl+Shift+D` or `dex pane split`) opened a terminal that could not start, because its folder was the file itself. It now opens in the folder the file is in.

## New

- **Settings gear.** The gear at the right of the title bar opens **Settings**, where you choose PowerShell or a WSL distro, with the same offer to restart running panes. If the chosen distro isn't ready for agents yet, Settings says why and, where Dex can fix it, takes you to the setup panel. It's also in the palette as *Settings*.
- **A + on every pane.** The **+** in a pane's header opens a new terminal beside it, in that pane's folder and in the chosen terminal, as `Ctrl+Shift+D` does for the active pane. Want `Ctrl+N` for it? Add `split-right = "Ctrl+N"` under `[keys]` in `config.toml`. Dex doesn't bind it by default, because plain `Ctrl+<letter>` keys belong to the shell (in bash, `Ctrl+N` is the next command in history).

## Known limitations

- A pane is either PowerShell or the chosen distro, one distro at a time.
- **macOS:** privacy prompts can name Dex (**Don't Allow** is safe); clicking a notification opens Script Editor (#40); the Intel build hasn't been run on an Intel Mac.
- Scrollback doesn't survive a restart, diff and markdown panes poll, and the installers are unsigned.

## Verification

In CI: 449 Rust tests on Windows, 448 on macOS, and 444 frontend tests. Each fix was written as a failing test first. Every change had a production-level review, and all its findings were fixed.

A GitHub build of these changes was run locally against a real Ubuntu distro:
- the startup pane restarted into Ubuntu and back;
- the settings gear and **+** worked as described.

The Restart-button fix was also checked in Edge against a stand-in backend. The button was live the moment the question appeared, where it had been dead for 2.7 s before the fix.
