# Dex 0.1.2

Dex now tells you when there is a newer Dex.

**Download:** `Dex_0.1.2_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet — SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it; your workspaces, hooks and settings are kept.

## New

**Update pill.** At startup and every six hours, Dex asks GitHub for the latest release. When it is newer than the one running, a **NEW · update x.y.z** pill appears in the title bar beside `activity`; clicking it opens the release page in your browser. Dex never downloads or installs anything by itself — you read the notes and run the installer, as before, but now you know there is one to run. The check is one request to GitHub's public API carrying only Dex's version. Turn it off with:

```toml
[updates]
check = false
```

This is the first release the pill can announce: from 0.1.2 on, that is how you will hear about the next one.

## Known limitations

Unchanged from 0.1.1: Windows only, no WSL agents yet, scrollback does not survive a restart, diff and markdown panes poll, unsigned installer. Tested against Claude Code 2.1.273.

## Verification

217 Rust tests, 111 frontend tests. The pill was exercised against the live GitHub release: a build versioned 0.1.0 showed `NEW · update 0.1.1` within seconds of starting.
