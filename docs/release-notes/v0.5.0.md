# Dex 0.5.0

Dex runs on macOS: Apple Silicon and Intel Macs, alongside Windows.

**Download:**
- **Windows:** `Dex_0.5.0_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet — SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it; your workspaces, hooks and settings are kept.
- **macOS:** `Dex_0.5.0_macos_apple-silicon.dmg` for an M-series Mac, `Dex_0.5.0_macos_intel.dmg` for an Intel one (**About This Mac** says which). macOS 11 or later, with Claude Code and Git installed (`xcode-select --install` gives you Git). They appear a few minutes after the release, once they are built.

## New

### Dex on macOS

Open the `.dmg` and drag **Dex** to **Applications**. This build is not signed or notarized by Apple yet, so the first launch is blocked once:

1. Open Dex, and click **Done** when macOS says it cannot check it.
2. Open **System Settings → Privacy & Security**, scroll to the message that Dex was blocked, and click **Open Anyway**. It is there for about an hour after the blocked launch; macOS asks once more, and for your password.

Or, in Terminal, `xattr -dr com.apple.quarantine /Applications/Dex.app`, and open it normally.

Everything Dex does on Windows it does on a Mac: workspaces, splits, the office, agents spawning agents in their own worktrees, shared context, the setup panel. What differs:

- **Keys.** Every `Ctrl` shortcut is `Cmd` — `Cmd+Shift+P` for the palette, `Cmd+1`…`Cmd+9` for workspaces, `Cmd+Shift+W` to close a pane — and moving between panes is `Cmd+Option+Arrow`, leaving `Option+Arrow` to jump by word in the shell and Claude Code. `Ctrl` combinations all go to the terminal. A `[keys]` override is taken as written and can name `Cmd`.
- **Panes** run your own shell (`$SHELL`, zsh by default) as a login shell, so your `PATH` and profile load. The `dex` command is in every pane; to have it in other terminals, put `/Applications/Dex.app/Contents/MacOS` on your `PATH` (the README has the line).
- **Quitting.** `Cmd+W` does nothing — it is one key from `Cmd+Shift+W`, and closing the window would end every agent. `Cmd+Q` and the window's close button ask first while panes are open. Quitting ends everything the panes started.
- **Notifications** appear in Notification Center.
- **The title bar** keeps the Mac's own traffic lights.

### Also on Windows

- Tooltips and the sidebar show a shortcut as you have bound it, not as it ships.
- A `[keys]` override that takes another action's key is reported, naming the action it leaves without one.

## Known limitations

- **macOS privacy prompts.** Programs running in a pane — Claude Code started in your home folder, most of all — can make macOS ask whether *Dex* may access Downloads, Music, or other apps' data, because macOS names the app hosting the terminal. Terminal and iTerm get the same prompts. **Don't Allow** is safe; opening a workspace on a project folder rather than your home folder avoids most of them.
- **Clicking a Mac notification** opens Script Editor, not the pane, and the banner is labelled Script Editor (#40).
- If Dex crashes on a Mac, background jobs started in its panes can outlive it; on Windows they cannot.
- The Mac build is not notarized, and has been run on an M4 Pro Mac; the Intel build is built and checked on every change but has not been run on an Intel Mac.
- No WSL agents yet, scrollback does not survive a restart, diff and markdown panes poll, unsigned installers.
