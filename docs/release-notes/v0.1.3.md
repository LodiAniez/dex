# Dex 0.1.3

One fix, from a report against 0.1.2.

**Download:** `Dex_0.1.3_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet — SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it; your workspaces, hooks and settings are kept. From 0.1.2 on, the update pill in the title bar points here.

## Fixed

**Agents whose pane was closed no longer haunt the spawn limit.** Closing a pane — or losing one when a Dex session ended — left its agent recorded as `idle` with no pane and no end time. Those rows counted toward the six-agent limit, so a workspace could refuse new spawns while `dex agent list` showed nothing running, and `dex agent stop` on them said "already ended" while the list still showed them. Now:

- the spawn limit counts only agents that have a pane;
- the watchdog ends any agent whose pane is gone (`pane closed`) within fifteen seconds, and the UI updates;
- `dex agent stop` on such an agent ends it and succeeds instead of refusing;
- a spawned child whose shell never appears is ended as `never started` rather than left idle for ever.

If you have stale rows from an earlier version, they are cleaned up on the first watchdog pass after you start 0.1.3 — nothing to do by hand.

## Known limitations

Unchanged: Windows only, no WSL agents yet, scrollback does not survive a restart, diff and markdown panes poll, unsigned installer. Tested against Claude Code 2.1.273.

## Verification

Two new regression tests reproduce the report's shape — an agent registered in a pane that is then closed — and hold that it stops counting at once, is ended by the sweep, and can be stopped.
