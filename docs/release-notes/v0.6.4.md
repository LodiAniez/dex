# Dex 0.6.4

A message to an agent that has finished its turn now wakes it (issue #58), and a label names an agent in your own workspace (issue #59).

**Download:**
- **Windows:** `Dex_0.6.4_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet, so SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it, and your workspaces, hooks and settings are kept.
- **macOS:** `Dex_0.6.4_macos_apple-silicon.dmg` for an M-series Mac, `Dex_0.6.4_macos_intel.dmg` for an Intel one. macOS 11 or later. The first launch needs **Open Anyway**, as before.

All three appear a few minutes after the release, once GitHub has built them.

## Fixed

- **A message could sit unread forever.** `message_send` said *Sent*, and an agent that had finished its turn never saw it: the wake-up was decided only as the message was stored, and only for an agent's *first* unread message. So a message that arrived while an agent was working waited for someone to give that agent a turn — in one real workspace, eight messages sent over an hour were read together, after the owner nudged the agent by hand.
  - The watchdog now looks for agents sitting at their prompt with messages waiting, and types the one-line prompt into their pane: within 15–20 seconds of the turn ending. Not the hook that ends the turn — Claude Code waits on its hooks, and text typed into a session that is still starting up is swallowed.
  - An agent that ends its turn on a question for you is left alone: its pane is waiting for your answer, and the nudge would be typed as that answer.
  - The sender is told what became of the message, rather than a bare *Sent*: **woken**, **waiting for their next turn**, **waiting on you**, or **nothing will read it, that agent has ended**.
  - A nudge that cannot be typed — a pane whose shell has gone — is tried again at the next sweep instead of being counted as delivered.
- **A label could name an agent in another workspace.** Labels are unique *within* a workspace, but the lookup behind every label searched all of them and took the most recently started match. With two workspaces open and role-style labels, `message_send`, the office's **Prompt** and `dex agent stop reviewer` could each reach a stranger: a message delivered to the wrong agent, text typed into the wrong pane, or the wrong session ended.
  - A label is now looked for in the caller's own workspace — the pane the command came from, or the one `--workspace` names. Ids are unchanged: they are unique, and reach their agent from anywhere.
  - Two workspaces with a pane of the same name are no longer an *ambiguous target* to someone standing in one of them.
  - `dex agent stop <label>` run outside any pane, with that label at work in several workspaces, says which they are and asks for `--workspace` rather than guessing.

## Changed

- **`dex agent list --json` and `agents_list` carry an unread count** for each agent, so a sender can see whose messages are piling up.
- **`dex agent stop` takes `--workspace`**, for naming an agent by label from outside any pane.

## Known limitations

- Waking an agent types into its pane, wherever your cursor is: a half-written line in that pane is submitted with the nudge. Digests are not typed — they reach an agent through its hooks — so they never interleave.
- An agent Dex has lost track of (`unknown`) is woken too, since a dropped `Stop` hook looks exactly like an agent that finished quietly. Dex checks first that Claude Code is still running in the pane, but only where the process table can be read; in a WSL pane whose distro does not answer, a nudge can still be typed into a bare shell, which runs it as a command.
- An agent spawned without a repo in a workspace whose root is your Windows home folder, and running in WSL, logs a harmless failing hook. Claude Code reads the home folder's settings as project settings there. Use a workspace root other than the home folder to avoid it.
- A pane is either PowerShell or the chosen distro, one distro at a time.
- **macOS:** privacy prompts can name Dex (**Don't Allow** is safe); clicking a notification opens Script Editor (#40); the Intel build hasn't been run on an Intel Mac.
- Scrollback doesn't survive a restart, diff and markdown panes poll, and the installers are unsigned.

## Verification

In CI: 502 Rust tests on Windows and 478 frontend tests; macOS runs the same suite without the Windows-only platform tests. Both fixes were written test-first, and the tests were mutation-checked — the fix reverted, the suite seen failing — including the one case a test suite over a temp database cannot see for itself: a nudge that really lands in a real shell.

Each fix went through production-level review, three rounds for the waking and two for the labels, and every blocker and should-fix was fixed before merge. Those rounds found, among others: a wake spent on typing that never happened, which would have left that message unread for good; a timed-out write to a stuck pane collecting a fresh nudge every sweep; and an "ambiguous label" error firing inside a single workspace, where the flag it asked for would have changed nothing.

Tested with simulated Claude Code hooks, following Claude Code's documented events. The waking has not been watched against a live Claude Code session yet.
