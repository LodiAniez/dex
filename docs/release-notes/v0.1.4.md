# Dex 0.1.4

The activity log can be pruned.

**Download:** `Dex_0.1.4_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet — SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it; your workspaces, hooks and settings are kept. The update pill in the title bar points here from 0.1.2 on.

## New

**Remove activity you no longer need.** The activity pane kept every event for ever, including those of agents long gone. Now:

- hover an event for **×** to remove just that one;
- **clear ended** removes everything agents that have since ended did — what live agents and you have done stays;
- **clear all** empties the workspace's log.

The two clears ask first, since they remove what anyone watching the workspace can see. From a terminal: `dex context delete <seq>`, `dex context clear`, `dex context clear --all`. Agents are unaffected: their digests are driven by sequence numbers, so gaps in the log cost nothing.

## Known limitations

Unchanged: Windows only, no WSL agents yet, scrollback does not survive a restart, diff and markdown panes poll, unsigned installer. Tested against Claude Code 2.1.273. One small new one: while the setup panel or the command palette is open, a pane opened underneath it by an agent takes keyboard focus, so Escape no longer closes the dialog — click its backdrop or button instead.

## Verification

221 Rust tests, 111 frontend tests, and a live run: notes from a live agent, an ended agent and a human; *clear ended* removed the ended agent's events and kept the rest; *clear all* emptied the log; deleting a missing event reported it.
