# Dex 0.6.2

See an agent's screen up close in the office, and prompt them from it.

**Download:**
- **Windows:** `Dex_0.6.2_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet, so SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over an earlier version upgrades it, and your workspaces, hooks and settings are kept.
- **macOS:** `Dex_0.6.2_macos_apple-silicon.dmg` for an M-series Mac, `Dex_0.6.2_macos_intel.dmg` for an Intel one. macOS 11 or later. The first launch needs **Open Anyway**, as before.

All three appear a few minutes after the release, once GitHub has built them.

## New

### An agent's screen on a monitor

In the office, click an agent, then **⤢ Expand** beside their screen. Their terminal opens in the middle of the window on a desktop monitor, with their name on the bezel, a status light (amber working, blue blinking when they're waiting for you, green idle, off when stopped) and a stand.

- **Live and in colour:** it's their terminal as it is, updating as they work. You can scroll back, and select text and copy it with Ctrl+C.
- **Prompting:** the monitor's last line is a prompt line. Type as in a terminal; nothing reaches the agent until **Enter**, which sends it as **Prompt** does, with the same checks. If they can't take a prompt right now, for example while waiting at a permission dialog, the line says why and sends nothing.
- **Only watched:** their pane isn't moved or touched. It carries on in the terminal view, or in a window of its own if you popped it out, and the monitor follows it between windows.
- **One at a time:** it's a modal. Nothing behind it responds until you close it with **Esc** or **✕**. The title bar stays usable.

## Fixed

- A pane's scrollbar could show through the office view while its terminal scrolled.

## Known limitations

- A pane is either PowerShell or the chosen distro, one distro at a time.
- **macOS:** privacy prompts can name Dex (**Don't Allow** is safe); clicking a notification opens Script Editor (#40); the Intel build hasn't been run on an Intel Mac.
- Scrollback doesn't survive a restart, diff and markdown panes poll, and the installers are unsigned.

## Verification

In CI: 449 Rust tests on Windows, 448 on macOS, and 478 frontend tests, including new ones for the monitor's copy stream, how it follows a pane between windows, and its prompt line. The monitor had three rounds of production-level review; every blocker and should-fix was fixed.

It was tested in a copy of Dex built by CI, against a stand-in agent:
- the live screen;
- a pane popped out into its own window, and docked back with the monitor open;
- a prompt typed on the monitor reaching the agent.

Copy, Tab, and closing a pane with its monitor open were tested in Edge, and you tried it with a real Claude Code session.
