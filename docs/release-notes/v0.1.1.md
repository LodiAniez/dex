# Dex 0.1.1

Two fixes from the first real use of 0.1.0, and a new icon.

**Download:** `Dex_0.1.1_x64_en-US.msi` below. Windows 10 1809+ or Windows 11, with Claude Code and Git for Windows installed. Not code-signed yet — SmartScreen will say *Windows protected your PC*; click **More info → Run anyway**. Installing over 0.1.0 upgrades it; your workspaces, hooks and settings are kept.

## Fixed

**A message to a finished agent is now delivered.** Agents receive their siblings' notes and messages at the start of their turns — and an agent that had finished and was sitting idle at its prompt had no next turn, so a parent's "the requirement changed" waited forever. Dex now wakes an idle agent when a message arrives for it: it types a one-line prompt into the agent's pane telling it to read its inbox, and the agent picks up from there. Only for idle agents that have actually started, only for the first unread message; a busy agent still gets its messages at its next tool call, and one waiting on a permission prompt is never typed into. The `dex-agentic` skill now says this is how to change a child's task — no need to stop it and start another.

**Children spawned into your home folder now start.** Claude Code asks its folder-trust question every time it runs in the home directory, and Dex only answered that question for children it had put in a worktree. Children spawned into the parent's own folder stopped at the dialog. Dex now answers it for every child it spawns — a child never lands anywhere you did not already choose.

## Changed

- New icon: `</dex>`.
- `dex skill install | uninstall | status`, a `skill` check in `dex doctor`, and a third button in the setup panel. The installer ships the skill beside `dex.exe`.
- Apache License 2.0, with the license text shown by the installer.
- `dex hooks` and `dex doctor` no longer point at a retired PowerShell script.

## Known limitations

Unchanged from 0.1.0: Windows only, no WSL agents yet, scrollback does not survive a restart, diff and markdown panes poll, unsigned installer. Tested against Claude Code 2.1.273.

## Verification

216 Rust tests, 111 frontend tests, and a live reproduction of the 0.1.0 report: three children spawned at once into the home folder all started within 25 seconds; a requirement-change message to a finished one woke it in 10 seconds, and it redid its work under the new rule.
